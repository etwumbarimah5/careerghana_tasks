# Career Path Predictor

A simple machine learning project that predicts a career category based on a person's skills or interests.

## Career Categories

- Technology
- Arts
- Business
- Communication

## Tools Used

- Python
- Pandas
- Scikit-learn
- Decision Tree

## How It Works

The program uses a small dataset of skills and their career categories to train a Decision Tree machine learning model.

The user enters a skill or interest, and the trained model predicts the related career category.
