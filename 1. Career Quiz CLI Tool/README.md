# Career Path Quiz CLI Tool

## About the Project

The Career Path Quiz is a simple Python command-line program that helps a user identify a career area that matches their interests.

The program asks 10 multiple-choice questions. Each answer belongs to one of four career categories:

- Technology
- Art
- Business
- Communication

At the end of the quiz, the program adds up the scores for each category and displays the user's strongest career area.

## How to Run the Program

Make sure Python is installed on your computer.

Open the terminal or command prompt and run:

```bash
python career_quiz.py
